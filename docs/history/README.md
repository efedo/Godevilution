# Historical Documentation

This directory preserves project-specific plans and analyses that explain past
decisions but no longer describe current operation. Each document carries a
historical banner and date. Current contributors should begin with
the [documentation index](../README.md), [architecture](../csharp-authoritative-server-migration.md),
and [migration status](../migration-status.md). The
[completion plan](../completion-plan.md) is the only active delivery sequence;
phase numbers and pending tasks in these historical documents are superseded.

Inherited DevilutionX policy, release, packaging, and platform manuals were
removed from the active tree because Git history and the upstream project
remain the authoritative sources for that material.
